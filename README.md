# incident-response-projects
Manual and AI-assisted incident response simulation projects

Project 1: Manual Incident Response

This project demonstrates a manual incident response process using authentication log analysis. A simulated brute-force attack was detected and analyzed using Linux command-line tools.

Key Components:
	•	Log analysis (auth.log)
	•	Detection of brute-force attack
	•	Incident response actions

Project 2: AI-Assisted Incident Response

This project extends the manual analysis by incorporating AI tools to assist in log analysis and threat classification.
